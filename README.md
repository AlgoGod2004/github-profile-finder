# GitHub Profile Finder

A simple GitHub profile finder built with HTML, CSS and JavaScript.

## Features

- Search GitHub users
- Display profile picture
- Display username
- Display followers and following
- Display public repositories
- Link to GitHub profile
- Handle invalid usernames
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- GitHub REST API

## What I Learned

- DOM manipulation
- Event listeners
- Fetch API
- Promises
- Async/await
- Try/catch error handling
- Working with JSON
- Rendering API data dynamically
